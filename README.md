### Progetti

**[windows-ad-lab](https://github.com/loremona/windows-ad-lab)**: il mio laboratorio su
Windows Server 2025. Un dominio Active Directory costruito da zero in una VM: Domain
Controller con DNS, OU per reparto, GPO verificate con `gpresult` e uno script PowerShell
che crea gli utenti in blocco da un file CSV.

**[aws-quiz-master](https://github.com/loremona/aws-quiz-master)**: per preparare la CLF-C02.
È partito come uno script Python con Streamlit, poi è diventato un'app Flask e infine un
sito statico con 18 moduli e un simulatore d'esame. GitHub Actions rigenera i dati e lo
pubblica su GitHub Pages a ogni push.
→ [provalo](https://loremona.github.io/aws-quiz-master/)

**[linux-quiz-master](https://github.com/loremona/linux-quiz-master)**: per preparare la LPIC-1.
Una PWA che funziona anche offline, con 10 moduli sugli obiettivi d'esame, simulatori per il
101 e il 102 e i progressi sincronizzati tra PC e telefono con Supabase.
→ [provalo](https://loremona.github.io/linux-quiz-master/)

**[budget](https://github.com/loremona/budget)**: il mio primo programma Python scritto da
zero, una riga alla volta, senza partire da codice già pronto. Risponde a una sola domanda:
*quanto posso spendere oggi?*

**[python-trainer](https://github.com/loremona/python-trainer)**: un corso Python
interattivo in Streamlit, 35 moduli e 154 esercizi, orientato all'automazione.
